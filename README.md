# 🌐 Global Cyber Attack Analysis (2015–2024)

## 📌 Project Overview

This project analyzes global cyber attacks recorded between 2015 and 2024 to identify attack patterns, financial losses, affected users, targeted industries, attack sources, vulnerabilities, and geographical trends.

The project combines Python-based data cleaning and Exploratory Data Analysis (EDA) with an interactive Power BI dashboard to transform raw cybersecurity data into meaningful insights.

---

## 🎯 Project Objectives

- Analyze global cyber attack patterns from 2015 to 2024
- Identify the most common types of cyber attacks
- Analyze financial losses caused by different attacks
- Understand the number of affected users
- Identify the most targeted industries
- Analyze attack sources and vulnerabilities
- Compare cybersecurity incidents across countries and years
- Build an interactive Power BI dashboard for data visualization and analysis

---

## 📊 Power BI Dashboard

The cleaned data was used to create an interactive Power BI dashboard consisting of three pages.

### 1. Cyber Attack Overview

This page provides an overall view of the cybersecurity landscape, including:

- Total incidents
- Total financial loss
- Affected users
- Average resolution time
- Attack type distribution
- Target industries
- Financial loss by attack type
- Year-wise trends

### 2. Global Threat Intelligence

This page focuses on geographical and security-related analysis, including:

- Country-wise affected users
- Attack type ranking
- Financial loss by country
- Vulnerability distribution
- Incident resolution time
- Geographical threat patterns

### 3. Incident Analysis

This page provides detailed incident-level analysis using fields such as:

- Country
- Attack type
- Attack source
- Target industry
- Vulnerability
- Financial loss
- Affected users
- Resolution time

Interactive filters allow the user to explore specific years, countries, attack types, and industries.

---

## 🔎 Key Insights

Some of the major findings from the analysis include:

- DDoS was the most frequently recorded attack type.
- IT was among the most targeted industries.
- The UK recorded the highest number of incidents in the dataset.
- Zero-day vulnerabilities were a major attack source.
- VPN was associated with a high average incident resolution time.
- Financial losses and affected users varied significantly across countries and years.
- The interactive dashboard allows these patterns to be explored using filters.
